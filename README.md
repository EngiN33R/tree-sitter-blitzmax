# tree-sitter-blitzmax

[![CI](https://img.shields.io/github/actions/workflow/status/EngiN33R/tree-sitter-blitzmax/ci.yml?branch=main&logo=github&label=CI)](https://github.com/EngiN33R/tree-sitter-blitzmax/actions/workflows/ci.yml)

A case-insensitive Tree-sitter parser for BlitzMax NG (`.bmx` files).
Originally developed for the BlitzMax Zed extension and structured using the
Tree-sitter grammar repository template.

The grammar recognizes declarations, definitions, literals, line and `Rem`
comments, multiline strings and conditional compilation. Expressions are
deliberately permissive to support incomplete code while editing. Semantic
validation belongs to the BlitzMax compiler or language server.

## Development

Use Node.js 24 and pnpm 10.8.0:

```sh
pnpm install --frozen-lockfile
pnpm generate
pnpm test
```

Parser generation uses Tree-sitter CLI 0.25.10 and ABI 14 for compatibility with
the Zed extension. Commit generated parser sources alongside grammar changes.
Native tests require a C compiler; Rust binding tests use `cargo test`.
On Windows, use a Visual Studio developer shell with the C++ tools and Windows SDK available.

- `grammar.js`: syntax rules.
- `src/scanner.c`: scanner for block comments and multiline strings.
- `src/`: generated parser and Tree-sitter support headers.
- `test/corpus/`: parser regression cases.
- `queries/highlights.scm`: editor-independent highlighting queries.
- `bindings/`: C, Go, Node.js, Python, Rust and Swift bindings generated by
  `tree-sitter init`.

The template's initial-setup workflow has been completed and removed. CI tests
the parser on Linux, Windows and macOS, checks Rust bindings and validates query
syntax. Version tags create source releases; package-registry publication is not enabled.

## Zed integration

Place this checkout beside `zed-blitzmax`, or set `BLITZMAX_GRAMMAR_DIR` to its
location before preparing or testing that extension. Zed-specific outline,
indentation and other editor queries remain in the extension repository.

Published Zed extensions can reference this repository's public HTTPS URL and
pin a commit SHA under `[grammars.blitzmax]` in their manifest.
